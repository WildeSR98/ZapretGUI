# 🛡 ZapretGUI

**ZapretGUI** — это графическое приложение для Windows, которое помогает обходить блокировки интернета (DPI) с помощью утилиты [zapret](https://github.com/bol-van/zapret). Вместо работы с командной строкой и bat-файлами вы получаете удобный интерфейс с кнопкой «Запустить» и автоматическим подбором настроек.

Дополнительно приложение включает **встроенный Telegram-прокси** — если Telegram не работает напрямую, прокси поможет подключиться.

---

## Что умеет

- **Обход блокировок** — запускает zapret одной кнопкой, без командной строки
- **20 стратегий** — переключайте между готовыми настройками для YouTube, Discord, Twitch, Instagram, Google
- **Автоподбор** — оркестратор сам проверяет все стратегии и выбирает лучшую для вашего провайдера
- **Telegram-прокси** — встроенный MTProto прокси, подключение в 2 клика
- **Служба Windows** — можно установить как фоновую службу, чтобы работало без открытого окна
- **Авто-обновление** — при выходе новых стратегий приложение обновит их само

## Как пользоваться

### Первый запуск

1. Скачайте и распакуйте архив в любую папку
2. Запустите `ZapretGUI.exe`
3. При первом запуске приложение само скачает нужные компоненты (движок zapret, стратегии, списки)
4. Выберите стратегию в выпадающем списке на главной странице
5. Нажмите большую кнопку **запуска** в центре экрана

Если сайты (YouTube, Discord и др.) заработали — готово! Если нет — попробуйте другую стратегию из списка или запустите оркестратор.

### Автоподбор стратегии

Не хотите перебирать вручную? Перейдите на вкладку **Оркестратор** и нажмите «Запустить». Приложение автоматически проверит все стратегии и выберет лучшую для вашего интернет-провайдера.

### Telegram-прокси

1. Перейдите на вкладку **TG Прокси**
2. При первом входе согласитесь на установку компонентов (~12 МБ)
3. Нажмите **«Запустить прокси»**
4. Нажмите **«Открыть в Telegram»** — настройки прокси применятся автоматически

### Работа в фоне (служба Windows)

Чтобы zapret работал постоянно без открытого окна:

1. Выберите стратегию на главной странице
2. Перейдите на вкладку **Сервис**
3. Нажмите **«Установить службу»**
4. Zapret будет автоматически запускаться при включении компьютера

> ⚠️ Для установки службы нужны права администратора

## Сборка из исходников

Если хотите собрать приложение самостоятельно:

```bash
# Клонируйте репозиторий
git clone https://github.com/WildeSR98/ZapretGUI.git
cd ZapretGUI

# Соберите
dotnet build ZapretGUI.sln

# Опубликуйте (portable — требует .NET Runtime)
dotnet publish ZapretGUI/ZapretGUI.csproj -c Release -o publish-out --self-contained false

# Или self-contained (всё включено)
dotnet publish ZapretGUI/ZapretGUI.csproj -c Release -o publish-out -r win-x64 --self-contained true
```

### Структура проекта

```
ZapretGUI.sln
├── ZapretGUI/           # Главное WPF-приложение (интерфейс)
├── ZapretGUI.Core/      # Бизнес-логика, модели, управление службами
├── ZapretGUI.AI/        # ИИ-модуль для подбора стратегий
├── ZapretGUI.Updater/   # Модуль авто-обновлений
├── engine/              # Движок zapret (winws.exe, стратегии, списки)
└── tg-proxy/            # Telegram MTProto прокси (Python)
```

## Часто задаваемые вопросы

**Нужен ли антивирус/исключения?**
Некоторые антивирусы могут реагировать на `winws.exe` — это нормально. Добавьте папку приложения в исключения.

**Какую стратегию выбрать?**
Зависит от провайдера. Начните с `general.bat`, если не работает — попробуйте ALT-варианты или запустите оркестратор.

**Приложение не запускается?**
Убедитесь что установлен [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0/runtime), или скачайте selfcontained-версию.
